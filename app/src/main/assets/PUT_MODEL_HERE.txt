PUT YOUR TRAINED TFLITE MODEL HERE
==================================

Place your TensorFlow Lite model as:

    app/src/main/assets/neurosight_encoder.tflite

(There is currently NO model in this repository, which is why the app
opens fine but the "Demo Mode" overlay shows:

    Backend: not loaded (add neurosight_encoder.tflite to assets/)

The APK still builds and installs without a model; classification is simply
inactive until you add this file and rebuild.)


EXACT MODEL CONTRACT (must match NeuroSightClassifier.kt)
--------------------------------------------------------
Input:
    - 1x224x224x3 RGB image (float pixels 0-255 -> UINT8 when quantized)
    - Model is treated as INT8-quantized (MODEL_IS_INT8_QUANTIZED = true),
      so the input tensor is UINT8 and NO pixel normalization is applied.
    - The classifier resizes/crops any incoming frame to 224x224 internally.

Output:
    - 1x3 scores, one per class, in this EXACT order:
          index 0 -> "wall"
          index 1 -> "door"
          index 2 -> "person"

    If your model outputs logits rather than probabilities, the classifier
    applies softmax and takes the max; if it outputs probabilities directly
    (or is quantized), the raw scores are read and the max index is used.


HOW TO BUILD A WORKING APK
--------------------------
1. Drop the .tflite file at the path above (git add it).
2. Commit and push; the "Build APK" workflow runs automatically, or trigger
   it manually from the Actions tab (Run workflow).
3. Download the "neurosight-debug-apk" artifact and install it.

To switch to a FLOAT32 (non-quantized) model, set
MODEL_IS_INT8_QUANTIZED = false in
app/src/main/java/com/neurosight/app/ml/NeuroSightClassifier.kt.
