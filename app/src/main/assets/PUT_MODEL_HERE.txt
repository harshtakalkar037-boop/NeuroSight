PLACE YOUR TFLITE MODEL HERE
=============================

NeuroSightClassifier.kt expects a file named exactly:

    neurosight_encoder.tflite

to exist in this directory:

    app/src/main/assets/neurosight_encoder.tflite

Model contract (must match, or update NeuroSightClassifier.kt accordingly):
  - Input:  1x224x224x3, UINT8 (INT8-quantized model), RGB, values 0-255
            (or 0-1 float if you use a float model -- see the TODO in
            NeuroSightClassifier.kt for the quantized vs float switch)
  - Output: 1x3 float/uint8 array of class scores, in this order:
            index 0 -> "wall"
            index 1 -> "door"
            index 2 -> "person"

Delete this file once the real .tflite model is added. It exists only so
the assets folder is tracked and the project structure is clear.
