NEUROSIGHT v2 TFLITE MODEL
===========================

The Android app loads the model from:

    app/src/main/assets/neurosight_encoder.tflite

The model must match this exact contract:

Input:
    1x224x224x3 RGB, UINT8, raw 0-255 pixels.

Output:
    1x5 UINT8 scores in this exact order:
        index 0 -> door
        index 1 -> window
        index 2 -> chair
        index 3 -> table
        index 4 -> cabinet

The training/export script is:

    training/train_neurosight.py

Run it against the Kaggle Indoor Object Detection dataset to generate the
replacement model. The script also writes neurosight_labels.txt.

IMPORTANT
---------
The current v2 source dataset contains door/window/chair/table/cabinet data.
It does NOT contain wall or person labels. Do not claim that the v2 model
recognizes wall or person until a model containing those classes has actually
been trained and evaluated.

After generating the model, copy the resulting file to this exact asset path
and rebuild the Android app.
