# 🎯 What if a phone could help you sense the world?

For a blind or low-vision user, a smartphone camera already has the ability to observe the environment.

NeuroSight explores what happens when we connect that camera to an **on-device AI model** and translate its understanding into a **learnable language of touch and sound**.

Instead of simply saying:

> "There is a door."

NeuroSight explores:

```text
Camera sees
     ↓
On-device AI understands
     ↓
Environmental class
     ↓
Haptic + Audio encoding
     ↓
User senses the information
